# Проверка русской локализации — промежуточная v0.3

Ветка основана на `main` (`f2878e8`). Проверяется локализованная игра v0.2; новая сюжетная кампания ожидает продолжения оборванного задания и в эти результаты не входит.

- TypeScript strict: проверка прошла.
- Vitest: 49 тестов прошли, без пропусков. 37 проверяют существующие игровые системы, 12 — русские формы слова «яйцо», локализацию карты, персонажей, атак, диалогов и сообщений сохранения.
- Production build и упаковка единого HTML прошли с `/chiken-simulator/`. Версия пакета отмечена как предварительная `0.3.0-alpha.1`.
- Итоговый полный запуск Playwright: **5/5 прошли за 40,5 секунды**, без пропусков. Четыре прежних сценария проверяют: полное прохождение до чемпиона, мультитач/отмена касаний, миграция и настройки, мобильная компоновка.
- Пятый сценарий локализации проверяет видимый текст и подписи доступности на отсутствие английских слов (буквенные клавиши разрешены), надпись магазина на Canvas и отсутствие обрезания кнопок. При визуальной проверке обнаружен выход справки за край на 667 px; ширина окон ограничена экраном, справка на узком телефоне переведена на две колонки.

Браузерные проверки используют настоящий Chromium, реальные события клавиатуры и касаний и управляемые часы. Это не физический Android. Игровой прогресс в сценарии прохождения не подделывается; только тест миграции намеренно загружает старое сохранение.

Схема сохранения и постоянные идентификаторы объектов не менялись. Английские идентификаторы исходников сохранены; весь пользовательский текст централизован. Новая кампания, её враги и способность не объявляются реализованными или проверенными.

Сборка: JavaScript 69,22 КБ + CSS 23,58 КБ; около 30,84 КБ вместе после gzip. Единый HTML — 94 111 байт. Форматирование и проверка пробельных ошибок Git пройдены.
